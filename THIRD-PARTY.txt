FLASH DRUM - THIRD-PARTY COMPONENTS
===================================

Flash Drum is free software, distributed under the GNU General Public
License v3 (LICENSE.txt). The VST3 interface it is built on (vst3-sys)
is itself GPL v3, which is why the whole plugin is.

It is built on the components below. The full text of every license
mentioned here is in THIRD-PARTY-LICENSES.txt, installed next to this
file.


RUST FRAMEWORKS (compiled into the plugin)
------------------------------------------

  nih-plug ....... VST3 plugin framework (patched copy) ... ISC
  vst3-sys ....... VST3 interface bindings ................ GPL v3
  baseview ....... plugin window .......................... MIT / Apache 2.0
  egui-baseview .. egui <-> window bridge (patched copy) .. MIT
  egui ........... user interface ......................... MIT / Apache 2.0
  clap-sys ....... CLAP bindings (not used by the VST3) ... MIT / Apache 2.0

  ...plus about a hundred smaller Rust libraries (MIT, Apache 2.0,
  Zlib, ISC, BSD, Unlicense, Unicode), all listed in
  THIRD-PARTY-LICENSES.txt. One of them, option-ext, is under the
  Mozilla Public License 2.0: it is used unmodified, and its source code
  is available at https://crates.io/crates/option-ext


PORTED SOUND CODE
-----------------

  The six AC606 voices (Bd6Ac, Sd6Ac, Hh6Ac, Oh6Ac, Cl6Ac, Tm6Ac) are
  ported from analogcode's "606-Inspired-Synth-Drums".
